CashTokens

via Paytaca BCMR registry

BCMR is a metadata registry, not a token index — there's no "browse all tokens" feed to pull from, so this looks up one token category at a time. Paste a CashToken category ID (the 64-char hex genesis txid) to fetch its registered metadata.

Mining pool distribution isn't shown for the same reason token browsing isn't: attributing blocks to pools means parsing each block's coinbase transaction and matching it against a pool-tag registry — real infrastructure work, not a data-fetch. Not implemented rather than faked.
